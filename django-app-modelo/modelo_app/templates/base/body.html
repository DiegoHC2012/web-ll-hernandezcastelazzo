Instrucciones:

  1. Crear página index de su proyecto en Django al ir a la URL 127.0.0.1:8000 y mostrar la página principal.
  2. Desde la lista de usuarios, al presionar el botón “Ver” deberá redirigir a la página donde se encuentra el formulario para editar la información del usuario.
  3. Crear la pantalla donde se podrá ver el formulario de actualización de usuario:
    • Maquetar formulario con todos los campos editables.
    • Mostrar los datos correspondientes del usuario en cada campo del formulario.
    • Debajo del formulario, mostrar en una tabla todas las direcciones del usuario seleccionado.
  4. Crear el método POST para que, al presionar el botón “Actualizar”, se realice la actualización de la información del usuario.
  5. Diseñar el Header y Footer creados en la última clase.
  6. En el Header, agregar las secciones Orders y Users para navegar a sus respectivos listados.
  7. Cada pantalla debe tener su propio archivo CSS y JS (este último será utilizado en clases futuras).
  8. El diseño de las pantallas queda a la creatividad del alumno.
